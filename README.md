### 🔮 Proyecto Destacado: **ViZzo** 👓💻

**ViZzo** — _Plataforma Full-Stack de Análisis Estático y Visualización 3D/XR de Software_ (Trabajo Fin de Grado)

> **ViZzo** es un analizador de código estático que genera una representación tridimensional e interactiva de las relaciones y estructuras del código fuente utilizando tecnologías WebXR.

- 🔍 **Pipeline de Análisis Estático:** Minería de repositorios (GitHub/GitLab) integrando **Lizard (AST multihilo)** y **PyDriller** con algoritmos de muestreo optimizados para bases de código masivas.
- 🕶️ **Frontend 3D/XR Inmersivo:** Desarrollado con **A-Frame** y **BabiaXR**, renderizando hasta **8 dashboards interactivos** en tiempo real.
- 🧠 **Integración IA & Síntesis de Voz:** Inferencia con modelos LLM (**DeepSeek**, **Grok**, **OpenAI**) para diagnósticos arquitectónicos dinámicos y narración por voz (**TTS-1**).
- ⚙️ **Backend Desacoplado:** Desarrollado en **Django** con persistencia en **PostgreSQL**, caché inteligente y servidor de producción **Gunicorn + WhiteNoise**.
- 🐳 **Docker, CI/CD & Despliegue VPS:** Suite de **39 tests unitarios** con `Django TestCase` y pipeline de **CI/CD en GitHub Actions** con despliegue automático vía **SSH** sobre un **VPS** con **Docker y Docker Compose**.
