---

### 🔮 Proyecto Destacado: **ViZo** 👓💻

Actualmente estoy desarrollando mi Trabajo de Fin de Grado (TFG) llamado **ViZo**:
> **ViZo** es un analizador de código estático que genera una representación tridimensional e interactiva de las relaciones y estructuras del código fuente utilizando tecnologías WebXR.
* **Backend:** Python + Django / Flask para el parsing, análisis semántico y estructuración de datos.
* **Frontend 3D:** HTML/JS utilizando **A-Frame** para renderizar grafos interactivos en el espacio 3D.
* **Integración IA:** Conectando con modelos locales a través de interfaces como **LM Studio** para resúmenes automáticos y refactorizaciones sugeridas en 3D.
